decomposition are separate specification and implementation decisions.
Rust's Cargo edition remains `"2024"`; edition, product version and manifest
schema are independent.

## Implementation and compatibility

Filesystem project loading, ordinary source/CLI compilation, source-documentation
reads and sized-module loading require the closest enclosing manifest. Missing
or malformed manifests, invalid field types and unsupported editions fail before
source parsing; nearer invalid or symlinked manifests cannot be skipped.
In-memory source APIs keep the current 2026 grammar. The standard-library
manifest is embedded beside its source. QLT files receive edition coverage
checking only; QLT execution remains deferred.

This adds the parse-only TOML 0.8.23 dependency to frontend configuration.
The independent IR verifier, evidence kernel and quantum semantics are unchanged.
Raw IR is still independently checked without source-manifest configuration.

Requiring a manifest is an incompatible filesystem-input requirement. The user
explicitly selected v0.2.3 for it, a narrow PATCH exception documented in
[versioning](../versioning.md#version-identity). Migrate previously manifest-free
projects by adding the minimal edition declaration. Preserve other public API
shapes, source meanings, namespace resolution, capacities and proof gates.
Original `.qli`/`.qlt` bytes, historical diagnostics, source hashes and
third-party licenses are retained.
