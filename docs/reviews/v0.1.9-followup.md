# v0.1.9 review follow-up in 0.2.0 development

Date: 2026-09-28. The user supplied the review and requested corrections during
the already selected [0.2.0 implementation](../releases/v0.2.0.md). The published
0.1.9 release/tag is unchanged. This record does not turn its historical B019
validation into a claim about the new capacity policy or general Rust soundness.

## Dispositions

| Finding | Implementation and independent check | Compatibility |
| --- | --- | --- |
| R1: fresh exact budgets per static construction/call | One 10,000,000-unit exact budget spans a compilation, including unused static arguments, provider/function evidence, transformations and IR verification. Repeated matrix work cannot reset it. A ten-level five-bit argument passes once but two calls exhaust it in the regression. Immutable shared source storage is charged once per allocation; metadata is still checked on every receipt, preserving the 100 KB/256-provider regression with an additional 25 KB module. | Newly aggregate capacity restriction: 0.2.0 MINOR. Source-byte overrides do not bypass it. This is an operation budget, not a wall-clock guarantee. |
| R2: bare CR hides code | The lexer rejects non-CRLF CR inside/outside all comment forms at the original byte. LF and CRLF remain valid. Tests repair the exact attack source to CRLF and observe the previously hidden X. | New lexical restriction: 0.2.0 MINOR. Convert bare-CR files explicitly; no silent reinterpretation. |
| R3: closed static transforms unchecked | At most six interface bits, compare emitted adjoint/repeat/control circuits against independently extracted verified-IR meanings, with phase and ordered axes. Cache closed meanings. Reuse `contract::invert_steps`. Tests submit structurally valid wrong-phase/control/axis circuits and require equation mismatch. | The comparison uses existing finite rules, with their extractor/dependency capacities and the new aggregate budget. Above six bits, existing structural checks remain; general transformation proof remains open. |
| R4: sequential power evaluation | Exact square-and-multiply uses at most 24 matrix products for counts through 4,096. A root-of-unity oracle checks phase, zero and boundary counts under a logarithmic work allowance. | Algorithmic optimization; no approximate equality. Execution still performs/counts each actual repetition. |
| R5a: corpus links absent | Normal document discovery includes every `corpus/**/*.md`; a missing corpus link is a tested failure. Corpus report metadata now reads the package version instead of hard-coding 0.1.9. | Compatible CI coverage/report correction. |
| R5b: duplicate helpers | One basis conversion helper and audited inversion routine; `VerifiedProgram::program()` remains a documented alias delegating to `raw()`. | Public accessors retained. Sharing code is not a trusted-core reduction. |
| R5c: source symlink replacement | Secure opening checks all path components on macOS, or walks held directory descriptors with no-follow opens on the listed Linux architectures; check the opened descriptor is a regular file. Deterministically replace a discovered file and its parent directory with symlinks before open; both reject. | Linux requires readable `/proc/self/fd`; errors fail closed. Other targets retain the previous filesystem trust assumption. No filesystem sandbox or concurrent-write snapshot guarantee. |
| R5d: unhashed Python validators | Pinned wheel SHA-256 values, `--require-hashes` and `--only-binary=:all:` in the requirements consumed by CI. Packages remain validation-only. | Versions/licenses unchanged; no Rust dependency added. |

The new source-opening flags use the macOS SDK's `sys/fcntl.h` and the Linux
[UAPI definitions](https://raw.githubusercontent.com/torvalds/linux/v6.12/include/uapi/asm-generic/fcntl.h).
Linux support here is x86/x86_64, ARM/AArch64 and RISC-V; its no-follow path is
covered by the same test in Linux CI, not executed locally on this macOS host.
The Python wheel hashes were obtained from the pinned
[OpenQASM 3 release metadata](https://pypi.org/pypi/openqasm3/1.0.1/json) and
[ANTLR runtime release metadata](https://pypi.org/pypi/antlr4-python3-runtime/4.13.2/json),
then checked by pip during installation in a fresh temporary environment.

## Reproduction and validation

[First source and observations](../../tests/fixtures/review_v019/README.md) were
retained before repair. The reduced five-bit/two-level repetition case changed
from 12.333 to 0.892 seconds in local debug checks. The reviewer supplied the
larger timings and three-hour extrapolation; those were not independently run.
CI asserts semantic results and work-unit exhaustion, never elapsed time.
The finite transformed-circuit comparison evaluates its first circuit chunk
directly; it does not pay for a redundant cubic multiplication by identity.
Later chunks retain ordered exact composition and the empty circuit is identity.
