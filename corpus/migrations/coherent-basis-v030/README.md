# Explicit coherent-basis corpus snapshots

Issue #81 replaces the two existing `do`/`pure` expressions with
`basis input as pattern { body }`. These complete four-file QLI snapshots
retain the exact input, binder, basis-body bytes, tuple shape, ordinary types,
owner flow, axis order and signed-permutation contracts. Every surrounding
comment and notice is preserved. Both `main.qli` files remain byte-identical.

The frozen original [LessThan translation](../../qualtran/less_than2/README.md)
and [DoubleExcitation translation](../../pennylane_demos/vqe_excitation/README.md)
retain their pinned Qualtran and PennyLane sources and Apache-2.0 attribution.
The original project roots and every earlier migration are unchanged.
The shared [schema-2 manifest](../../Qargo.toml) retains edition 2026.

`first-sources.json` and `before-corpus-manifest.json` record the selected
predecessor identities before observation or migration. The byte-preserved
README metadata copies have raw `.txt` names after capture; the explicit
`metadata-archive.json` path map records that archival rename. Their links
continue to be maintained in the original roots. First QLI sources, predictions,
identity records, raw observations and emitted artifacts are unchanged.

`span-observations.json` records the existing parser helper's actual offsets.
Only each coherent expression's spelling changed. `migration.pending.json`
preserves the initial proposal; `migration.json` and `selection.json` record
the subsequently validated explicit source selection. The strict corpus
manifest check confirms all four predecessor/after identities, complete
snapshots and actual check observations.

`observations-before/capture.json` and `observations-after/capture.json` each
register six actual successful commands: check, default run and IR emission
for both existing 5/4-qubit projects. Both parsed default distributions match
exactly. Both emitted QIRF files match byte-for-byte: 1,266 bytes for LessThan
and 1,348 bytes for DoubleExcitation. `checks.json` binds the two AFTER checks
to the selected snapshot identities. No build, download or new maximum case
was generated or executed.

Default probabilities alone do not establish relative or controlled phase.
The byte comparison retains the existing checked IR, but these observations
are neither an independent upstream oracle nor a universal source-preservation
proof. QS, PR, RS, broader profile/body obligations and release gates remain
separate. These snapshots do not implement generic QFT or validate an updated
external qlippy consumer. Observation commands are data; do not replay them.
