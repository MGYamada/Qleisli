## Status

**Qleisli 0.3.0 semantic-boundary umbrella.**

This issue no longer owns broad Rust surface import. The release split is:

```text
0.3.0 — define the quantum/Rust semantic boundary
0.4.0 — Rustify the complement (#251)
```

Related: #27, #29, #68, #69–#79, #85–#89, #196, #251.

## Thesis

Rust is a useful prior for Qleisli, but 0.3.0 must freeze **where that prior stops being trustworthy**.

> **Copy Rust where the semantics commute. Fork the syntax where they do not.**

0.3.0 therefore fixes the semantic firewall, not an exhaustive Rust feature set.

## Rules to freeze in 0.3.0

### No `unsafe`

There is no source-level escape hatch that bypasses ownership, effects, verifier acceptance, or constitutional guarantees.

### Scoped linear quantum ownership without implicit destruction

Lexical scope may structure quantum ownership, but scope exit does not authorize loss of live `Q<T>`.

```text
scope end != destroy
scope end = discharge obligation
```

### Familiar syntax only where familiar meaning remains valid

Rust-like spelling may be adopted in 0.3.0 only when needed to state a frozen semantic law or when the Rust intuition remains valid under Qleisli checking.

### Distinct syntax for distinct quantum meaning

The 0.3.0 boundary must cover coherent control, quantum disposal, coherent-control access, preparation/observation, ancilla lifecycle, indexing/views, panic/unwind, copy/clone/default construction, hidden autoref/autoderef, assignment, and physical SWAP.

Concrete decisions live in #68–#79 and related core issues.

## Explicit deferral to 0.4.0

Broad trait/impl ergonomics, associated items, rich ordinary patterns, advanced module/import conveniences, iterator/combinator authoring, formatter/punctuation compatibility, and other ordinary Rust surface features are evaluated under #251/#197/#61 in 0.4.0 unless separately required by the 0.3.0 semantic core.

## Frozen false-friend decisions — 2026-10-07

The 0.3.0 firewall now fixes these source-level boundaries:

- `&` is not quantum read access; use `ctrl`.
- `&mut` is not quantum exclusive access; use `excl`.
- `mut` does not grant quantum access and live quantum-containing places are not assignable.
- `q[i]` is a static place/axis selector; access mode is explicit.
- quantum autoref/autoderef/`DerefMut` does not infer access.
- `swap` is the physical SWAP operation; structural reordering is `permute_axes`.
- early `return`, `?`, panic/unwind and hidden abort are outside verified quantum execution.
- unrestricted closures cannot capture live `Q<T>`.
- live `Q<T>` has no ordinary Drop/Copy/Clone/Default/Eq/Ord/Hash semantics.
- “RAII” is not normative quantum terminology because scope exit does not run quantum destruction.

## Design intent

0.3.0 makes the **small quantum delta** precise. 0.4.0 can then import ordinary Rust vocabulary aggressively without repeatedly reopening the quantum laws.
