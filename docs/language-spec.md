# Qleisli 言語仕様草案

状態: v0.3 段階1に向けた議論用草案（2026-09-26）。[固定した設計思想](design-philosophy.md)、[コンパイル時健全性の開発目標](ai-era-goal.md)、先行する[段階0の構成](standard-library.md)と[量子言語としての条件](quantum-language-requirements.md)に従って、型と意味論を検討する。構文例は import を省略した断片であり、確定文法でも実行可能なコードでもない。[構文 v0 案](syntax-v0.md)に暫定的な字句・文法・スコープ規則と Rust パーサの実装上の深さ制限を分けて記す。

## 目標と意味論

Qleisli の純粋コアは、測定前の振幅と干渉を保つ計算を関数合成として記述する。初期版の基底型 `A` は `Unit`、`Bit` とそれらの有限積で、意味を `Vec(A) = H(A) = C^(A)` とする。`Vec` は自由ベクトル空間モナドを説明する**数学的な記号**であり、ソースの `Q<A>` はその任意の `bind` を公開するモナド型ではない。実行可能な純粋コアは、その Kleisli 射のうち等長性を保証した操作で構成する。

プログラム全体の合成は、概念上 `(古典入力; 量子文脈 Δin) -[効果 ε]-> (古典出力; 量子文脈 Δout)` と読む。`Q<A>` はこの文脈内の所有権型であり、効果 `ε` と同一視しない。前後の量子文脈が適合する変換を順に合成するという Kleisli 的な原理を採る。正確な効果判断と形式構造は段階1で定める。下記の `do/pure` は単射基底リフトに限り、プログラム全体の合成を表す構文ではない。

純粋なプログラム `Iso<A, B>` の意味 `V : H(A) -> H(B)` は `V†V = I_A` を満たす。`Unitary<A, B>` はさらに `VV† = I_B` を満たす。有限個の古典パラメータ `γ` がある関数は、各 `γ` ごとにこの条件を満たす写像の族 `V_γ` と解釈する。初期版の純粋関数は非再帰で、反復は静的な有限回数に限る。これにより型付けされた関数は停止し、全域の線形写像を表す。一般の `A -> H(B)` を受け取る無制限の `bind` は実行可能な操作として公開しない。

ゲート記述と IR は全体位相を保持する。`U` と `exp(iθ)U` を制御付きにすると、その差が制御枝の相対位相になるため、操作値を全体位相で同一視しない。

## 型

- 基底型: `Unit`、`Bit`、有限積 `(A, B)`。`Bit` は基底ラベルの型であり、測定結果そのものを意味しない。
- `Q<A>`: 基底型 `A` を持つ論理量子レジスタの所有権。線形に使用する。複数のレジスタが絡み合えるため、所有権は個別の純粋状態ではなく、共有する全体系への操作権を表す。線形文脈全体の意味は単一の結合状態上で定める。
- `Iso<A, B>`: 関数宣言と IR に付ける、等長なコヒーレント操作の静的分類。初期版では第一級のソース値型ではない。
- `Unitary<A, B>`: 関数宣言と IR に付けるユニタリ操作の静的分類。初期版では第一級のソース値型ではない。`adjoint` はまずこの分類だけに定義する。
- `CBit`: 測定結果など、通常の古典的な真偽値。

`Q<(A, B)>` は絡み合った二体系を表せる。`split : Q<(A,B)> -> (Q<A>, Q<B>)` と逆向きの `join` は、互いに素な論理ワイヤの所有権を再束縛する構造操作であり、振幅には作用しない。分割後も全体系の状態は絡み合っていてよい。ゲートと測定は、分割した部分系に作用できる。複数ハンドルへのゲートではワイヤ ID の重複を拒否する。借用との衝突は変数名でなくワイヤ ID 集合の重なりで検査し、生きた借用を含むハンドルの `split`・`join` は初期版では拒否する。

`CBit` はコピー可能だが、コヒーレントな基底添字 `x : A` はコピー可能な実行時古典データではない。`x` を式中で複数回書いてよいのは、単射な基底写像など、全体が等長になる静的構成に限る。

## 純粋コアの規則

型検査では、コピー可能な有限型の古典パラメータ `Γ`、コヒーレント基底添字 `x : A`、線形な量子所有権 `Δ` を区別する。主な判断は `Γ, x : A ⊢basis e : B`、`Γ ; Δ ⊢ q : Q<B>`、`Γ ⊢ K : Iso<A, B>` である。`basis fn` は有限型上の全域・非再帰関数とし、コンパイル時に `Γ` の各値について有限の真理値表へ展開できる。実行時 `CBit` に依存する純粋操作は、値ごとの検査後に古典分岐として IR 化する。基底添字から `CBit` を作る操作はない。

`do x <- q; e(x)` の `x` はコヒーレントな基底添字であり、古典的な測定値ではない。この継続は量子資源を捕捉しない。初期版では `do x <- q; pure e(x)` を、下記の単射規則の構文糖衣として受け入れる。一般のモナド `do` を実行可能な構文として認める段階ではない。複数の量子資源を使うときは、先に共同レジスタ `Q<(A, B)>` にまとめる。

基底式の `not`、`xor`、`and` は有限ビット上の全域な基本演算とする。`and` のように非単射な基底関数も古典的な基底計算には使えるが、それだけを量子レジスタへ持ち上げることはできない。

基底式 `e : A -> B` が単射なら `lift(e) : Iso<A, B>` を作れる。有限の真理値表で単射性を検査し、IR に `LiftBasis(e)` として保持する。有限型の間なので、これは初期化した作業ビットを含む可逆な基底置換へ拡張できる。初期処理系は `LiftBasis` を直接シミュレートし、ハードウェア向けのゲート合成は別のバックエンド責務とする。`LiftBasis` は入力の所有権トークンを消費して新しいトークンを返す。初期 IR では入力ワイヤの順序と ID を保ち、幅が増えた出力の追加ワイヤだけに新しい論理 ID を付ける。一般の継続 `k : A -> H(B)` を許すには、すべての `a, a'` について `〈k(a), k(a')〉 = δ(a,a')` と、実行可能な IR への変換をともに示す別の規則が必要である。

操作の合成とテンソル積は等長性を保つ。`Q<A>` の所有権は実行される各経路で一度だけ使用し、暗黙に破棄しない。量子ゲートは入力の所有権を受け取り、更新後の所有権を返す。初期ゲート集合には `X`、`H`、`Z`、`T`、`CNOT`、`Toffoli` を含め、`T|1〉 = exp(iπ/4)|1〉` と定める。`T` により複素位相を表現できる。合成、テンソル積は等長性を保存し、静的操作変換を `adjoint : Unitary<A,B> -> Unitary<B,A>` と表す。これは初期版の通常の高階関数型を意味しない。

`qif(control, target) { 0 => U0, 1 => U1 }` は、相異なる所有ワイヤの `Q<Bit>` と `Q<A>` を消費して両方を返す制御付きユニタリである。両枝に `Unitary<A,A>` を要求し、制御ビット自体の基底ラベルは変えない。意味は `|0〉〈0| ⊗ U0 + |1〉〈1| ⊗ U1` とする。`U0`、`U1` の全体位相も制御付き操作の相対位相として保持する。古典値 `CBit` による `if` は排他的に一枝を選ぶ。両枝が同じ型・ワイヤ集合のユニタリなら `unitary fn` にも置け、`if` 自体は測定効果を生まない。枝の効果が `observe` なら全体も `observe` になる。

```qli
unitary fn choose(b: CBit, q: Q<Bit>) -> Q<Bit> {
    if b { x(q) } else { q }
}
```

`choose` は `b = 0` では恒等、`b = 1` では `X` というユニタリの族である。`b` が上流の測定結果なら、呼び出し元の `observe fn` が測定効果を保持する。

### 例: 基底情報の共有

```qli
iso fn entangle(q: Q<Bit>) -> Q<(Bit, Bit)> {
    do x <- q;
    pure (x, x)
}
```

`x -> (x, x)` は単射なので `Iso<Bit, (Bit, Bit)>` となる。`q` は一度だけ使われる。意味は `α|0〉 + β|1〉 -> α|00〉 + β|11〉` であり、`|0〉` の補助ビットと CNOT に落とせる。

`do x <- q; pure 0` は単射でないので拒否する。`(q, q)` は量子所有権の二重使用なので拒否する。

## 補助量子ビットと借用

`init0() : Q<Bit>` は新しい論理ワイヤを `|0〉` で導入する等長な操作であり、返された所有権は呼び出し元が管理する。`with0` はスコープ内だけの補助ワイヤを導入し、終了時にゼロ復帰を静的に証明して解放する構文候補である。初期版で受け入れる `with0` は、下記の `with_computed` に展開できる形に限る。通常の `Q<Bit>` を無条件に捨てる操作は純粋コアに置かない。純粋な解放 `Release0(a)` は、**全入力について**補助ビットが `|0〉` に戻り、残りの系から分離している静的証拠がある場合だけ意味を持つ。局所写像 `〈0|` を任意状態に適用すると跡保存にならないため、初期 IR では `Release0` を独立した命令として公開しない。検証器が構造全体を調べる `ComputeUseUncompute` の内部操作とする。表層にも `release0 : Q<Bit> -> Unit` という無条件の関数や、実行時測定でゼロを確認する操作を置かない。

最初に採用する証明規則は `compute; use; uncompute` である。`compute` は記録されたユニタリ `C_f`、`use` は計算元と補助ビットの計算基底ラベルを保存する**ユニタリ** `W`、`uncompute` は記録された `C_f†` とする。計算元の `Q<A>` は `C_f` の開始から `C_f†` の終了まで凍結し、`use` の間はコヒーレント制御としてだけ借用できる。この借用は古典値の読み出しではない。借用寿命中の測定、リセット、破棄、基底ラベルの変更を禁止する。寿命だけではゼロ復帰を示せないため、`W` の保存効果も検査する。

一般の作業レジスタ `R` がある場合、許可する `W` は `H(A) ⊗ H(Bit) ⊗ H(R)` 上の `Σ(x,b) |x,b〉〈x,b| ⊗ V(x,b)` という形で、各 `V(x,b)` は `R` 上のユニタリである。`R = Unit` なら `W` は計算元と補助ビットに位相だけを加えられる。合成全体は `|x〉|r〉 -> |x〉V(x,f(x))|r〉` を実現し、任意の入力・参照系との絡み合いに対して逆計算後の補助ビットは必ず `|0〉` で分離する。`use` 中に `R` を測定することも認めない。

初期版の保存効果は構文的に認証する。恒等操作、保護中のワイヤ上の対角位相ゲート、保護中のワイヤを制御にして `R` へ作用する制御付きユニタリ、それらの合成を受け入れる。任意のゲート列が偶然この形に等しいかを一般的に判定する機能は要求しない。現行の[試作 IR](ir-prototype.md) の制御付き標的操作は、保護ワイヤを制御とする一量子ビットゲートに限る。標的間ゲートや一般の利用者定義ユニタリまで受理するという上記の記述は、まだ実装済みの保証ではない。

全域の基底関数 `f : A -> Bit` について `C_f|x,b〉 = |x,b xor f(x)〉` は可逆である。補助ビットに `Z` を作用させてから逆計算すると `|x,0〉 -> (-1)^f(x)|x,0〉` となる。この `f` に単射性は要求しない。

次は構文候補である。`with_computed(q, f)` は `q` の所有権を受け取り、`|0〉` の生成、`C_f`、保存効果付きの `use`、`C_f†`、静的なゼロ証明に基づく解放を行って `q` を返す。ブロックの `a` は一時的な `Q<Bit>` で、ブロック末尾はその更新後の所有権を返す。作業レジスタ `R` を扱う拡張形では `q` と `R` の所有権を返す。ブロック内の操作の合成から保存効果を導出できない場合は型エラーにする。

```qli
basis fn f(x: Bit) -> Bit { not x }

unitary fn phase_oracle(q: Q<Bit>) -> Q<Bit> {
    with_computed(q, f) { |a|
        z(a)
    }
}
```

ここで `z(a)` は基底ラベルを保って位相を与えるユニタリである。`f(x) = not x` なので、この例の結果は `-Z` である。全体位相 `-1` も IR で保持する。この例ではブロック内から計算元 `q` を参照しない。計算元をコヒーレント制御として借用する一般形の束縛構文は未決である。

## 測定による論理所有権の終了（暫定決定）

測定は `Iso` の合成には含めず、古典結果を伴う量子インストルメントとして扱う。`observe fn` は純粋操作と測定・リセット・破棄・古典分岐を合成できるが、`iso fn` と `unitary fn` から `observe fn` を呼べない。量子入力 `A`、固定された量子出力型 `B`、有限の古典入力 `γ`、古典出力 `c` を持つ関数の意味は、各 `γ,c` に対する完全正写像 `E_{γ,c} : L(H(A)) -> L(H(B))` である。`L(H)` は線形演算子の空間で、各 `γ` について `Σ_c E_{γ,c}` は跡保存とする。結果確率は `tr(E_{γ,c}(ρ))`、サンプル後の状態はそれで正規化したものとする。続く操作 `F_{d|c}` との合成は `(c,d)` 枝ごとに `F_{d|c} ∘ E_{γ,c}` と定め、内部結果を返さない場合は該当する枝を足し合わせる。古典分岐の合流でも量子出力型 `B` は一致させる。

`measure_z(q) : Q<Bit> -> CBit` は測定対象の論理所有権を消費し、量子ハンドルを返さない。`q` が他のレジスタと絡み合っている場合も、結果 `b` の残系への写像は `E_b(ρ) = tr_q((P_b^q ⊗ I_rest) ρ (P_b^q ⊗ I_rest))` とする。`split` した一部分だけを測れ、残る所有権の状態は結果 `b` に条件付けられる。`reset(q)` は測定前に所有する `q` を受け取り、旧状態と相関を捨てて、新しい論理 ID `q'` の `|0〉〈0|` を準備する。意味は `|0〉〈0|_{q'} ⊗ tr_q(ρ)` である。`discard(q)` は `tr_q(ρ)` によってワイヤを消費する。これらは不可逆な効果であり、純粋な `release0` と区別する。

測定時点で `q` の論理的な寿命は終わる。型検査は旧所有権トークンを消費し、同じワイヤ ID と重なる生きた借用がある測定を拒否する。測定結果の `CBit` は古典値として残り、別の量子ワイヤへのフィードバックに使える。物理素子が破壊されるという主張ではない。

再び量子ビットを使うときは `init0()` で新しい論理 ID を得る。Z 基底の一量子ビット測定では、結果 `b` に条件付けた測定対象の状態は `|b〉` で残系から分離するため、新しい `|0〉` ワイヤへ `b` に応じて `X` を適用すれば、結果付きの量子状態を再準備できる。これは物理ワイヤの同一性を保証しない。古典分岐の合流では、両枝が同じ入力ワイヤ集合を互換な型で返す場合に、新しい SSA 所有権トークンへ合流させる。枝内で作った一時ワイヤは枝内で閉じる。補助計算を守る借用寿命は、測定後の物理素子の利用とは別の概念である。

```qli
observe fn reprepare_z(q: Q<Bit>) -> (CBit, Q<Bit>) {
    let b = measure_z(q);
    let fresh = init0();
    let prepared = if b { x(fresh) } else { fresh };
    (b, prepared)
}
```

`prepared` は新しい論理ワイヤであり、`measure_z` が返したハンドルではない。この等価な再準備は初期版の一量子ビット Z 測定の性質を使う。将来の退化測定や部分系を保持する測定へ無条件に一般化しない。

```qli
observe fn feedback(q: Q<Bit>, r: Q<Bit>) -> (CBit, Q<Bit>) {
    let b = measure_z(q);
    let r1 = if b { x(r) } else { r };
    (b, r1)
}
```

この例では `q` の所有権は測定で消費され、結果 `b` で別のワイヤ `r` への `X` を選ぶ。`if` の各枝は同じ線形入力文脈を**排他的に**受け取り、それぞれの枝で `r` をちょうど一度消費して、互換な `Q<Bit>` を返す。したがってソース上で両枝に `r` が現れても二重使用ではない。`CBit` は `q` の寿命が終わっても測定履歴として保持できる。測定前の `q` の干渉は戻らない。

バックエンドは、途中測定、古典フィードバック、新しい論理ワイヤの準備に必要な機器能力を検査する。条件が合えば、測定済みの物理素子へ新しい論理 ID を割り当てられる。言語の意味論は機器能力によって変えず、実現できないプログラムは拒否する。

## 閉じたプログラムの例

エントリポイント `observe fn main() -> T` は古典結果 `T` を返し、終了時に所有する量子ワイヤを残さない。量子サブルーチンでは `Q<A>` を返してよい。下の例は Bell 状態を作り、一方ずつ測って結果を返す。`split` は絡み合いを壊さない。

```qli
observe fn main() -> (CBit, CBit) {
    let q = h(init0());
    let pair = entangle(q);
    let (left, right) = split(pair);
    let a = measure_z(left);
    let b = measure_z(right);
    (a, b)
}
```

このプログラムは `(0,0)` と `(1,1)` をそれぞれ確率 `1/2` で返す。二回の `measure_z` は両方の量子所有権を消費する。

## 最小 IR とコンパイル境界

型検査後の IR は、論理ワイヤ ID 集合と所有権の消費・生成を SSA トークンで追い、`Init0`、`LiftBasis`、位相を含む `Gate`、`ControlledGate`、`Split`、`Join`、`MeasureZ`、`Reset`、`Discard`、`ClassicalBranch`、構造化された `ComputeUseUncompute` を持つ。`MeasureZ` は入力ワイヤを消費して古典結果だけを返す。各命令には入力・出力ワイヤ ID 集合と新規 ID の割当を明記する。`with_computed` は `Init0; C_f; W; C_f†; Release0` の全体を表す構造ノードへ下げ、検証器が `f` の全域性、`W` の保存効果、逆演算の対応、ゼロ復帰を再確認する。独立した `Release0` 命令は持たない。各命令の入力トークンは一度消費し、必要な出力トークンを作る。分岐合流では互換な所有権を φ ノードで束ねる。

IR 検証器は、ワイヤ重複、所有権漏れ、借用 ID 集合との衝突、測定などで消費した旧トークンの参照、効果の逆流を拒否する。さらに `LiftBasis` の単射性、列挙されたゲート構成子のユニタリ性、`W` の保存効果、`ComputeUseUncompute` 内の `C_f` と `C_f†` の対応を、任意の IR 入力について再検証する。初期シミュレータは有限次元の状態ベクトル・密度演算子を直接評価できる。ハードウェア出力では `LiftBasis` のゲート合成と動的機能の適合性をバックエンドが検査する。これは意味論と型検査から区別した実装条件である。

Rust は処理系の実装言語とする。Rust の借用検査は処理系自身のメモリ安全性を助けるが、Qleisli ソースの等長性、コヒーレント制御、補助ビットのゼロ復帰は上記の型検査器と IR 検証器が保証する。

## 診断と残る設計項目

コンパイラは、非単射な `pure` 継続、量子資源の二重使用・暗黙破棄、量子添字の古典的な読み出し、証明のない `release0`、純粋関数中の測定、保存効果に反する `use`、分岐後の所有権不一致を位置付きエラーとして報告する。

| 断片 | 判定 | 根拠 |
| --- | --- | --- |
| `entangle(q)`、Bell 生成と部分測定 | 受理 | 単射な基底写像、線形所有権、インストルメント |
| `phase_oracle(q)` | 受理 | `C_f† W C_f` と補助ビットの静的ゼロ証明 |
| `feedback(q,r)`、`choose(b,q)` | 受理 | 測定した `q` の消費、排他的な古典分岐と線形出力 |
| `let b = measure_z(q); h(q)` | 拒否 | 測定で消費した論理所有権の再利用 |
| `do x <- q; pure 0` | 拒否 | 非単射で等長でない |
| `(q, q)` | 拒否 | 同じ量子所有権の複製 |
| `with_computed` の `use` 中で単独の `H(a)` または測定 | 拒否 | 基底保存・純粋性に反し、ゼロ復帰を示せない |
| 借用した `q` と ID が重なる部分系の測定・リセット | 拒否 | 補助計算の依存元を壊す |

この草案は、有限個の量子ビットを使う小さなプログラムの主要な型・意味論条件を整合的に提案する。文法と完全な型規則はまだ定まっていない。処理系を完成させるまでに、次を固定する。

1. 表層文法、関数呼び出しとスコープ、型推論の範囲、`with_computed` と `qif` の正確な構文。
2. サイズ付きレジスタと静的な反復・配列操作。これがないと一般の量子アルゴリズムを自然なサイズ変数で書けない。
3. 回転角と精度の表現。`H/T` などだけの初期核を超えるアルゴリズム・ゲート合成で必要になる。
4. `LiftBasis` と保存効果の検査・合成アルゴリズム、および IR 検証器の実装。
5. 将来、測定後の量子系を保持する非破壊測定が必要になれば、標準の `measure_z` と区別できる API と意味論を設計する。初期版の測定は量子ハンドルを返さない。
6. **所有権とエンタングルメントの境界。** `split` で分けた所有権から分離状態を推論せず、局所ゲート・部分測定・破棄を全体系上で合成する型・効果判断を定める。関数の署名や IR に、純粋な補助ビット解放に必要な分離証拠と、最適化に必要な依存情報をどこまで持たせるか決める。一般のエンタングルメント判定を前提にしない。
