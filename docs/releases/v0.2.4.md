one meter. All six complete first sources are saved before checking, and the
baseline compiler accepts them without repair. The first semantic run passes
264 probes and detects six paired type-correct faults. These informed authoring
observations are not a measured model benchmark or upstream-framework run.

[VM-24](../../tests/fixtures/verification_v024/README.md) moves original finite
circuit/evidence data and phase-sensitive encoded equations into the pure Lean
kernel. Actual-definition proofs cover column traces, reference action, clean
return from the required encoding and both whole-space inverse laws. Fresh
complete-artifact checking derives dependencies and compares the independent
root request. [Issue 128](https://github.com/MGYamada/Qleisli/issues/128) tracks it.
RawProgram extraction and transport/production integration remain later packets.

[Issues 116–119](https://github.com/MGYamada/Qleisli/issues/116) supply four
compatible frontend repairs: reject symlink/non-file manifests portably,
enforce sized entry/provider visibility, reject `check --basis` as usage, and
document/diagnose the existing Linux procfs requirement. Private entry selection
and cross-module providers violated module visibility; the basis flag was
specified only for execution. These repairs do not adopt new acceptance rules.
The [bug validation](../../tests/fixtures/issue_fixes_v024/validation.json)
records fresh Rust builds, regression results and remaining platform checks.

The [0.2.3 review response](../../tests/fixtures/review_v023/README.md) adds five

LiftBasis synthesis have separate future Issues. No new language form, public
Rust/IR/Lean declaration, acceptance rule, capacity, dependency or toolchain change. Edition 2026 and Rust 1.85 remain in force.
The frozen VM-22 36-case/12-fault census and comparison bytes are preserved.
Rust remains production-authoritative and external schemas remain disabled.
