# Nine small translations for 0.2.8

Three additions per approved frozen source, with one to three data qubits.
Upstream commits, reviewed files and licenses are unchanged. The
[manifest](../../manifest.json) fixes symbols, interfaces, meanings and exclusions.

[Session](session.json) preserves all complete first sources before checking.
All nine [first checks](check-initial.json) passed, with zero source repairs.
These are informed translations with repository, upstream and oracle access,
not controlled model benchmarks. No upstream framework was executed.

The W-state example keeps its auxiliary input/output owner explicitly. The
auxiliary is zero on the promised preparation input only; arbitrary-input
complex comparisons do not grant general pure release. Other examples cover
offset superpositions, even parity, coherent carry, equality input restoration,
zero reflection, signed rotations and a QAOA path sharing its middle wire.

[Current semantic validation](../../validation-v0.2.8.json) compares every
complex entry through X/Y interference and detects nine paired, type-correct
faults. Tolerance 1e-11 is numerical testing, not exact evidence or a general
translation proof. No new maximum-size experiment is included.
