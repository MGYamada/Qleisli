## F2 reproduction

This was a curated replay of the supplied review, not a new controlled
authoring or model-performance study. The frozen input in the
[JSON record](b019-2026-09-28.json) has a 2,919-byte `main.qli`, 40 distinct
one-gate unitary providers and one Apply-only generic helper. The same binary
and main were checked first alone and then with an unimported `unused.qli`
containing `//`, 25,000 ASCII `p` characters and a newline (25,003 bytes).

| Project | Actual result |
| --- | --- |
| Main only | JSON `ok`, verified, exit 0, empty stderr. |
| Identical main plus unused comment file | JSON `error`, `limit` at `main.qli:75:15`, exit 1, empty stderr. The message reports retaining 35,090 source bytes for a new binding, including all loaded modules, comments and bundled std. |

The 1,000,000-unit budget is unchanged. Each new provider copies and charges
the full source snapshot. This is not a semantic counterexample to unitary or
ownership checking; it is an unresolved documented capacity/accounting defect.
Thresholds depend on source size and other work and are not guaranteed limits.

To replay from the repository root after building the current CLI:

```sh
python3 - <<'PY'
import json
import subprocess
import tempfile
from pathlib import Path

record = json.loads(Path('docs/reviews/b019-2026-09-28.json').read_text())
binary = Path('target/v019-review/debug/qleisli').resolve()
with tempfile.TemporaryDirectory(prefix='qleisli-f2-') as directory:
    project = Path(directory)
    (project / 'main.qli').write_text(record['F2_reproduction']['main_source'])
    for add_unused in (False, True):
        if add_unused:
            (project / 'unused.qli').write_text('//' + 'p' * 25000 + '\n')
        result = subprocess.run([str(binary), 'check', directory, '--format=json'],
                                capture_output=True, text=True)
        print(add_unused, result.returncode, result.stdout, result.stderr)
PY
```

[A020-10](../v0.2.0-backlog.md#a020-10--source-snapshot-copies-exhaust-the-shared-lowering-budget)
retains concrete sharing/accounting alternatives and acceptance experiments.
Closing it requires an implemented, validated resolution consistent with the
published contract, or an explicit contract/migration decision that addresses
