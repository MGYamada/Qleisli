## Compatibility and migration

The [tuple correction](../tuple-shapes.md) is a breaking source/public-AST and
finite type-metadata extension. `(A,B,C)` no longer means `((A,B),C)`. Preserve
an old interface by spelling its binary nesting, or adopt a flat signature and
use checked explicit conversions. Existing binary sealed/library signatures
retain their contracts. The [type contract](../type-system.md) consolidates
formation, structural equality, ownership and implemented limits.

The subsequent [v0.1.9 review repairs](../reviews/v0.1.9-followup.md) additionally
introduce an aggregate 10,000,000-unit exact budget, finite closed-transform
comparison capacities and global bare-CR rejection. These are MINOR changes;
they do not reinterpret the published 0.1.9 rules. Convert bare-CR files to LF
or CRLF. The byte-policy legacy option does not disable exact work or lexical
checks. Source opening rejects concurrent symlink substitution on macOS and
the listed Linux targets; Linux requires readable `/proc/self/fd`.

The CLI now applies source byte limits before UTF-8 decoding/tokenization:
1 MiB per file and 16 MiB per project including bundled sources. Large projects
can explicitly use `--source-bytes=N --project-bytes=N` or
`--legacy-source-limits`. The override and legacy flag are mutually exclusive;
other parser, lowering and evidence bounds remain in force. This newly
restricting default requires MINOR under the adopted Cargo-compatible policy.

Existing `Project::load`, `compile_project`, `check_project` and their diagnostic
variants retain the old byte policy. New policy-bearing functions make the
choice explicit. `doc` bounds its one file and does not load bundled modules.
Source-size failures use `limit` with the path/limit in the message and no
invented character location. Syntax and all finite quantum rules are unchanged
by these machine-interface packets.

`sample` requires explicit canonical-decimal `--shots=N --seed=S`. The JSON
envelope remains version 1 with the specified sample result. Sampling advances
one SplitMix64 stream across freshly prepared trajectories. Deterministic and
hidden observations consume random words; errors produce no partial result.
`run` continues to return the exhaustive reference distribution.

`run_trials` retains typed retries and aborts on execution failure. The new
factor-trial API reduces validated period candidates to their minimal order
and checks nontrivial factors; the historical `factor_from_phase` behavior is
preserved. Neither API is a scalable modular-arithmetic circuit or general Shor.
