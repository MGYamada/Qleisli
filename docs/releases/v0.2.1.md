## README rendering repair

GitHub rejected the milestone formula's `\operatorname{verify}` macro.
Use `\mathrm{verify}` and basic `[\![p]\!]` double-bracket notation, preserving
the statement that acceptance implies satisfaction of the requested contract.
The expression uses GitHub's documented
[`math` block syntax](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/writing-mathematical-expressions#writing-expressions-as-blocks),
which retains the spacing escapes through Markdown processing. The v0.5.0
Soundness Theorem remains a planned milestone.
