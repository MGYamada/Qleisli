# 現行有限 IR の量子的健全性: 紙上の証明

状態: **現行 Rust IR を対象とする条件付きの数学的証明**（2026-09-26）。この文書は [有限コアの形式化](formal-core.md)を、現行の構成子と検証条件に即して展開する。数学上の解釈と Rust 実装の対応は監査対象であり、機械検証された証明ではない。対象は検証器が受理する有限 IR であって、未実装の .qli 型検査器や将来の任意の外部操作ではない。

## 1. 定理の正確な範囲

以下を仮定する。

1. 入力は安全な Rust API の verify が受理した RawProgram である。VerifiedProgram の非公開フィールドを改ざんせず、後続の変換も再検証する。
2. Gate、Cnot、Toffoli、ProtectedUse の位相を後述の**正確な複素数演算**で解釈する。有限精度の参照実行系の数値を等式の証拠にしない。
3. RawOp の実行は有限列と有限の ClassicalBranch 木で停止する。未報告の事後選択、失敗、外部量子操作、無限ループを加えない。
4. 各構成子の量子意味をこの文書の式と一致させる。特に分岐の QuantumPhi は位置ごとの軸改名であり、測定や量子状態の複製ではない。

**定理 A（資源）。** 受理された IR の任意の古典・測定経路では、生きた所有権トークンが互いに素なワイヤ列を所有する。演算子は生きたトークンだけを一度消費し、最終的な生存トークンは quantum_outputs にちょうど一度ずつ現れる。幅 0 の Q<Unit> も線形なトークンである。

**定理 B（純粋）。** 入力古典値 γ を固定する。導出効果が Unitary または Iso の受理 IR は、量子入力から量子出力への線形等長写像 V_γ を表し、V_γ†V_γ = I を満たす。導出効果が Unitary なら V_γV_γ† = I も満たす。宣言効果が Unitary なら検証器は導出効果も Unitary と要求するため、同じ結論を得る。宣言が Iso または Observe と弱くても、導出効果による性質は失われない。

**定理 C（観測）。** 任意の受理 IR、古典入力 γ、公開古典出力 b について、理想意味 E_{γ,b}: L(H_in) → L(H_out) は完全正かつ跡非増加であり、Σ_b E_{γ,b} は跡保存である。公開出力が空でも総和は一結果の CPTP 写像になる。古典出力を明示した写像 ρ ↦ Σ_b |b〉〈b| ⊗ E_{γ,b}(ρ) も CPTP である。

これらはプロトコルの正しさ、計算結果、実機のノイズ・能力を主張しない。定理 B の V_γ は**固定した古典入力ごと**の写像である。古典入力を量子制御へ暗黙に昇格させる定理ではない。

## 2. 文脈、軸、古典履歴

幅 n の BasisShape は {0,1}^n に対応し、H_n = ℂ^{2^n} とする。n=0 の Unit は一次元空間 H_0=ℂ であり、量子ワイヤは 0 本でも Q<Unit> の所有権トークンは残る。レジスタの wires=[w₀,…,wₙ₋₁] は**順序付き**で、局所ラベル x=Σᵢ xᵢ2ⁱ の bit i を wᵢ に置く。現在の live レジスタに属する全ワイヤは互いに素とする。

各検証時点の全体系 H(Δ) は、生存ワイヤを一度ずつ並べたテンソル積である。どの全体軸順序を選んでも、軸置換 P_π で一意に同型となる。入力ポートでは quantum_inputs の列順と各ポート内の wires 順、出口では quantum_outputs の列順と各レジスタ内の順を正準順序に選ぶ。中間演算は対象軸を前に移す P_π、局所写像、逆の軸配置で表す。単なるワイヤ ID の違いは状態の差ではない。入力密度演算子は全ワイヤ間で任意に絡み合ってよく、さらに外部参照系 S と絡み合ってよい。

古典環境 γ は ClassicalId ごとの bit 値の写像である。ClassicalNot と ClassicalXor はこの環境へ決定的な値を加える。量子基底ラベルを γ に書き込む操作は MeasureZ だけである。測定、Discard、Reset の隠れた Kraus 添字も含む**履歴** h ごとに、非正規化状態に作用する完全正写像 F_h と古典環境 γ_h を持たせる。最終的な classical_outputs の順序付き値が b になる履歴を足し合わせて E_{γ,b}=Σ_{h:out(γ_h)=b}F_h と定義する。古典出力の重複指定も古典値のコピーに過ぎない。公開されない測定結果や破棄の添字を消すときは完全正写像を**確率的に和**し、振幅を加えない。

古典入力は γ として固定する。量子入力が空でも、全体系が外部参照系と絡み合う開いた意味論を先に定義する。sim::run_closed は、この一般意味論のうち入出力の量子・入力古典文脈が空である例だけを近似数値で実行する。

## 3. 原始構成子の意味と局所補題

表示しないワイヤ R と外部参照系 S には恒等写像を作用させる。以下で「ユニタリ」は厳密な複素数上の等式を指す。

| 構成子 | 局所意味 | 等長性または Kraus 完全性 |
| --- | --- | --- |
| Init0 | V: \|ψ〉_R ↦ \|ψ〉_R\|0〉_q。q は新規ワイヤ。 | V†V=I_R。1 ワイヤ増えるので非全射。 |
| Gate | H=(1/√2)[[1,1],[1,−1]], X、Z、T=diag(1,e^{iπ/4}) を対象 bit に作用。 | 各 U†U=UU†=I。位相を商に取らない。 |
| Cnot、Toffoli | 制御 bit を保ったまま標的 bit を xor で反転する基底置換。 | 置換行列の逆は自身。 |
| Split、Join | 所有権トークンと順序付きレジスタの束ね方を変える。 | H_{m+n}≅H_m⊗H_n の正準な軸同型。状態には恒等または軸置換が作用。 |
| LiftBasis(table) | 全域表 f:{0,1}^n→{0,1}^m に対し V_f=Σ_x|f(x)〉〈x|。既存 n ワイヤを同順で保持し、追加の m−n ワイヤは新規。 | 表の出力が範囲内で相異なれば V_f†V_f=I。m=n なら有限集合の単射は全単射で VV†=I。 |
| MeasureZ | K_b=〈b\|_q⊗I_R、b∈{0,1} を古典出力に記録し q を終える。 | Σ_b K_b†K_b=I_{qR}。各 b は CP・跡非増加。 |
| Discard | 幅 k の対象レジスタについて K_z=〈z\|_Q⊗I_R、z∈{0,1}^k を隠す。 | Σ_z K_z†K_z=I。Σ_z K_zρK_z†=tr_Q(ρ)。k=0 では恒等。 |
| Reset | 旧 q を終え、新規 q′ を作る。J_b=\|0〉_{q′}〈b\|_q⊗I_R の b を隠す。 | Σ_b J_b†J_b=I、Σ_b J_bρJ_b†=\|0〉〈0\|_{q′}⊗tr_q(ρ)。 |
| ClassicalNot、ClassicalXor | γ に決定的な bit を加え、量子系には I。 | 各古典入力ごとに一結果の CPTP。 |

現行 IR の `QuantumIf` は、この表の封印ゲートから作る二つの有限な `UnitaryStep` 列を標的レジスタの同じ幅で検査する。各列は添字の範囲と相異なる制御・標的を確認した `H/X/Z/T/Cnot/Toffoli` および `ScalarPhase` の合成であり、それぞれ正確なユニタリ `U₀,U₁` を表す。外側の制御ワイヤは標的と相異なり、操作の意味は

    C = |0〉〈0|_c ⊗ U₀ + |1〉〈1|_c ⊗ U₁

である。射影の直交性から `C†C=|0〉〈0|⊗U₀†U₀+|1〉〈1|⊗U₁†U₁=I`、同様に `CC†=I`。`ScalarPhase` を各 `Uᵢ` の正確な位相として保持し、枝ごとの全体位相で同一視しない。標的が `Unit` でも `U₀=I, U₁=−I` は制御への `Z` になる。これは測定結果に応じて選ぶ `ClassicalBranch` と異なる。

表の単射が等長性を与える計算は V_f†V_f=Σ_{x,y}|x〉〈f(x)|f(y)〉〈y|=Σ_x|x〉〈x|=I である。表は**入力全体**に値を持つ必要がある。例えば bit の 0 と 1 をともに 0 へ送る表 [0,0] なら 〈V_f0|V_f1〉=1 となり、等長ではない。

MeasureZ、Discard、Reset の各演算子は任意の R、S に対して K⊗I_S または J⊗I_S として働く。この Kraus 形が完全正性を与え、完全性等式が総和の跡保存を与える。特に Bell 対の一方を Discard すると、他方は部分跡による混合状態となる。「別ワイヤを別々に所有する」ことから積状態を仮定していない。

## 4. 構造化した計算・使用・逆計算

ComputeUseUncompute の source は n bit、内部 ancilla は a bit、targets は相異なる 1 bit レジスタの列である。関数表 f:{0,1}^n→{0,1}^a は全域・範囲内であればよく、単射である必要はない。C_f|x,y〉=|x,y xor f(x)〉 は f が非単射でもユニタリで、C_f†=C_f である。

検証器が受け入れる use_ops は次の三種類に限る。

- ProtectedGate は source または ancilla の一 bit に対する Z または T。どちらも保護 bit の計算基底値を変えず、位相を保持する。
- ControlledTargetGate は保護 bit の真偽に応じて、別の target bit に H/X/Z/T を作用させる。制御判定は target の値に依存せず、各制御ブロック内でユニタリである。
- ControlledPhase は保護 bit の条件に応じて −1 または e^{iπ/4} を掛ける。target が 0 本の場合も位相を保持する。

したがって use_ops の列 W は、保護ラベル (x,y) を固定したブロック対角形 W=Σ_{x,y}|x,y〉〈x,y|⊗V_{x,y} と書ける。各 V_{x,y} は target 上のユニタリである。保護 bit に対する Z/T と ControlledPhase は V_{x,y} に複素数位相を掛け、ControlledTargetGate は該当ブロックの標的ユニタリを合成する。target が複数あってもこの帰納は成立する。

構造全体は初期化、計算、使用、同じ C_f による逆計算から成る。任意の x と target 状態 |t〉について

    |x,t〉|0〉 → |x,t〉|f(x)〉
             → |x〉 V_{x,f(x)}|t〉 |f(x)〉
             → |x〉 V_{x,f(x)}|t〉 |0〉

となる。線形性により任意の重ね合わせと参照系 S を含む入力で、最後の ancilla は厳密に |0〉として残りから分離する。これを外す実効写像 U_eff=Σ_x|x〉〈x|⊗V_{x,f(x)} は U_eff†U_eff=U_effU_eff†=I である。外部の生存ワイヤには I_R を掛ける。source が Unit のとき x は一つだけ、ancilla が 0 bit のとき f(x) は唯一の空ラベルであり、同じ式が成り立つ。

この証明は「いつか ancilla がゼロになるはず」という文字列や寿命宣言に依存しない。単独の Release0 を基底構成子に入れると、例えば |1〉 を 〈0| で消して跡を 0 にするため、跡保存と等長性が破れる。ProtectedGate の X/H、保護ラベルの測定・リセット・破棄、異なる関数による逆計算を受け入れないことが、上の因子分解の条件である。

## 5. 古典分岐と φ の補題

ClassicalBranch の condition は既に存在する ClassicalId である。古典環境 γ に対して選ばれるのは then または else の**片方だけ**で、両枝は同じ入力量子文脈から検査される。従って入力トークンが両枝の構文に現れても同じ実行経路で二度使われない。測定から得た condition なら、測定後の別々の古典履歴について枝を選ぶ。

各 QuantumPhi は、選ばれた枝の出力レジスタの第 i ワイヤを φ 出力の第 i ワイヤへ改名する。全生存レジスタが各枝で一対一に φ へ渡され、対応する幅が同じであり、φ の出力ワイヤは全域で新規かつ互いに素である。枝ごとの出力 H(Δ_then)、H(Δ_else) から共通 H(Δ_φ) への対応は、各レジスタ内の位置を保つ軸改名と必要な全体軸置換 P_then、P_else である。各 P はユニタリであり、積状態化、振幅の複製、観測をしない。ClassicalPhi は選ばれた枝の古典値を新しい SSA ID へコピーするだけである。

帰納仮定で各枝が等長なら、固定した γ では一方の V_arm しか選ばれず、P_arm V_arm も等長である。両枝がユニタリなら合成もユニタリ。観測枝については、選ばれた枝の各 Kraus 演算子の左に P_arm を掛けても完全性は保たれる。測定で分かれた古典履歴が後で同じ公開 b に合流する場合、対応する CP 写像を足し合わせる。**φ の合流で枝間の振幅を足さない**ため、条件が過去の測定結果に依存しても、総和の跡保存が成立する。

## 6. 合成による証明

**資源の帰納法。** 初期入力で各ポートのワイヤを reserve_wire し、各トークンを insert_token するので重複はない。consume は対象トークンの相異性と生存を確認した後に消費する。各通常構成子は、旧トークンを除いた後で、新規トークンを付けた互いに素なレジスタを挿入する。Init0、LiftBasis の追加ワイヤ、Reset、ComputeUseUncompute の内部 ancilla は reserve_wire で全域の新規性を調べる。Split/Join はワイヤ列を分割・連結するだけである。ComputeUseUncompute の ancilla は出力トークンにならず、上節の静的なゼロ復帰証拠で閉じる。分岐ではそれぞれの枝を同じ入力状態の複製された**検証状態**から検査し、全生存トークンの φ 被覆と新規出力を要求する。これはランタイムの量子状態の複製ではない。最後に quantum_outputs と生存集合の一致を調べる。有限操作列および枝木への帰納法で定理 A を得る。

**純粋写像の帰納法。** 単一の Gate、Cnot、Toffoli、同幅かつ単射な LiftBasis、Split/Join、QuantumIf、ComputeUseUncompute、および古典演算は、固定 γ でユニタリである。Init0 と幅を増す単射 LiftBasis は等長である。古典分岐には前節の補題を使う。等長写像の合成 V₂V₁ は (V₂V₁)†(V₂V₁)=V₁†V₂†V₂V₁=I であり、ユニタリの合成はユニタリである。局所操作に I_R と I_S を掛けても同じ等式が成り立つ。

検証器の導出効果は Unitary < Iso < Observe の上限である。Init0 と**幅を増す** LiftBasis は少なくとも Iso、MeasureZ、Reset、Discard は Observe に上げ、分岐は両枝の上限を取る。従って導出効果 Unitary の操作列・全枝に非ユニタリ構成子は現れず、等長のうち正方かつ単射な LiftBasis だけが残る。追加の unitary 宣言時の入力・出力 bit 数の一致も検査する。ただし**次元一致だけ**でユニタリ性を推論してはいけない。非単射表や測定を拒否する条件、効果上限の帰納が必要である。これで定理 B を得る。

**インストルメントの帰納法。** 純粋な V は一つの古典結果を持つ E(ρ)=VρV† であり、V†V=I なので CPTP。観測構成子は第 3 節の Kraus 完全性を満たす。前段の履歴 c の CP 写像 E_c と、そこで得た古典環境に応じた後段結果 d の CP 写像 F_{d|c} について、公開する結果が d のみなら G_d=Σ_c F_{d|c}∘E_c と定義する。完全正写像の合成と有限和は完全正であり、

    Σ_d G_d = Σ_c (Σ_d F_{d|c})∘E_c

の跡は各段の完全性により入力の跡と等しい。固定結果 d の G_d は正の入力で非負の跡を持ち、総和が入力の跡なので跡非増加である。古典分岐には前節の排他的選択を使い、ClassicalNot、ClassicalXor、ClassicalPhi は公開結果の再ラベルまたは隠蔽だけを行う。有限列と有限枝木への帰納法で定理 C を得る。全ての Kraus 演算子へ I_S を掛けた同じ帰納法が成り立ち、外部参照系との絡み合いを含む。

## 7. 検証器から式への対応義務

| 必要な条件 | 現行コードの入口 | 数学上の役割・残る監査 |
| --- | --- | --- |
| 線形トークン、異なる生存ワイヤ、出口の完全性 | verify.rs の State::consume、insert_token、verify の quantum_outputs 検査 | 定理 A の不変量。枝、幅 0、失敗時の状態変更を含めた実装監査は未機械化。 |
| 新規ワイヤと有限の幅 | State::reserve_wire、入力ポート検査、幅上限、check_table | 局所作用の対象軸と全域な有限表を確定。総生存ワイヤ数は検証器では無制限で、数値実行系は別の上限を持つ。 |
| 封印ゲートと位相 | ir.rs の SingleGate、ScalarPhase、ProtectedUse | 表中の**正確な**行列と各 enum 値の対応を固定・監査する。sim.rs は f64 近似であり証明器ではない。 |
| コヒーレント分岐 | verify.rs の QuantumIf 検査と UnitaryStep の添字検査 | 両枝を静的に検査し、制御を測定せず `P₀⊗U₀+P₁⊗U₁` と解釈する。枝位相を落とさない。 |
| 単射リフト | verify.rs の check_table(..., true)、LiftBasis のワイヤ接頭辞・新規性検査 | V_f†V_f=I を導く。幅増加で Iso へ上げることと、同幅での全単射性を確認する。 |
| 測定・破棄・リセット | verify.rs の幅・消費・新規性・Observe 効果 | 各 Kraus 形と完全性。Rust の実行系が混合状態を保持することは別の実装義務。 |
| 構造化した補助解放 | verify.rs の verify_compute、check_table(..., false)、check_protected_bit、check_controls | W が (x,y) を保ち、同じ C_f で逆計算するための十分条件。任意の Release0 を導入しない。 |
| 分岐と位置 φ | verify.rs の verify_branch と QuantumPhi、ClassicalPhi | 両枝の入力一致、出力の完全被覆、各 φ の幅一致・新規性。sim.rs の relabel_branch は軸名の改名であり、枝振幅の和ではないことを維持する。 |
| 効果と unitary 宣言 | State::effect、verify の宣言比較と入力・出力 bit 数比較 | Observe を純粋として、Iso を Unitary として宣言させない。次元一致は補助条件で、単独の証明ではない。 |
| 公開古典出力 | verify の classical_outputs 存在検査、sim.rs の確率集計 | 内部測定履歴を隠したとき CP 写像を和にする。古典出力 ID の重複はコピーとして読む。 |

現行コードと上の数式の行ごとの同値、実装の全経路を網羅した帰納的な形式証明、Rust の型系・コンパイラを含む信頼基盤の検証は**未完了**である。特に参照実行系は閉じたプログラムを f64 で実行し、零重み枝や容量上限を扱うので、その出力は定理 B・C の証明ではない。ソース `.qli` の暫定構文解析とモジュール名・import の解決はあるが、型・効果検査、RawProgram への変換と意味保存はまだ無い。将来の adjoint、関数呼び出し、借用、外部バックエンドをこの定理へ自動的に含めない。

## 8. 境界を示す反例と拒否

- 同じトークンを Cnot の control と target に渡す、または測定済みトークンを Gate へ渡す IR は State::consume が拒否する。これが資源の非複製・寿命検査である。
- Init0 したトークンを出力から黙って省くと verify の出口検査が拒否する。捨てたい場合は明示的な Discard と Observe 効果が必要になる。
- LiftBasis の表 [0,0] は全域でも単射でないため拒否される。一方 [0,3] は |0〉↦|00〉、|1〉↦|11〉という等長写像として受理できる。これは未知状態 |ψ〉↦|ψ〉|ψ〉 の複製ではない。
- Init0 を含むプログラムを Unitary と宣言すること、MeasureZ・Reset・Discard を Iso と宣言することは効果比較で拒否される。特に「入出力の総 bit 数が同じ」というだけでは観測の隠蔽を許さない。
- ComputeUseUncompute の保護 bit に X/H を作用させる use は拒否される。単独の Release0 は RawOp に存在しない。Bell 対の片方を所有しているだけでは純粋解放の証拠にならない。
- 分岐の一方が量子所有権を φ に渡し忘れる、両枝の対応幅が異なる、あるいは同じ出力を二重に対応づける IR は拒否される。既に測定から得た condition による合法な古典フィードバックは、測定の Observe 効果とともに受理できる。
