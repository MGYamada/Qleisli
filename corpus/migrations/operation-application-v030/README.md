# Canonical finite operation applications

This informed derivative migration implements the bounded client contract in
[Issue #33](https://github.com/MGYamada/Qleisli/issues/33). It changes 25
currently selected finite translation kernels from `adjoint(U, q)` to
`inverse(U)(q)` and from `repeat_static(k, U, q)` to `power(U, k)(q)`.
The complete desired projects and independent probe sources were saved before
execution or active source selection in [preparation.json](preparation.json)
and [probes.json](probes.json).

Frozen original translations, historical attempts, previous migrations,
upstream pins and licenses remain unchanged. Source notices retain Microsoft,
Google and PennyLane attribution and the translation copyright. The manifest
records every exact predecessor and derivative hash. The first copied edition
manifests have the same bytes as the actual inherited predecessor manifest.
The initial assembly incorrectly assumed each predecessor had a local manifest;
it stopped before execution. The preparation records that repair and retains
the two first QLI files unchanged.

The initial public selection rejected those extra local manifests: the existing
positive snapshot format binds QLI files and rejects additional inventory.
[Selection repair](selection-repair.json) preserves all copied manifest bytes
under `initial-manifests/`; active derivatives inherit the identical unchanged
`corpus/Qargo.toml`. It retains both actual failed Rust runs. No source statement,
observation, expectation or source-selection rule was weakened or changed.

Power's existing closed-provider profile uses ordinary private checked wrappers
for sealed `t` and `phase_eighth`. These wrappers are source programs, not new
primitives or implicit evidence. T's relative phase differs from the scalar
eighth root of unity. In particular, the two reflection clients retain four
scalar applications, including their complete minus sign under coherent
control. Fixed QFT calls, exact product trees, low-axis order, logical owners
and all original finite parameters retain their contracts. Generic QFT is
outside this migration and the v0.3.0 scope.

Actual original, derivative-check and derivative-run records are stored in
[predecessor-runs.json](predecessor-runs.json), [checks.json](checks.json) and
[runs.json](runs.json). The independent existing mathematical corpus oracle
checks each shipped input and one nonzero complex matrix entry through both
X and Y interference, with complete sources and raw observations in
[phase-results.json](phase-results.json). [Validation](validation.json)
states the actual coverage and CLI count. These selected entry checks preserve
phase evidence but are not full operator equivalence or a general
source-preservation proof. Semantic faults and rejection cases retain their
existing selection until a separate explicit migration.

Registration in the corpus's source-selection chain makes these complete
derivatives the maintained clients. Checking a snapshot before registration
does not establish that the public corpus harness selected it.
[Integration evidence](integration.json) records the actual all-87-project Rust
checks on both toolchains, the source-selection confirmation and the 77 Python
provenance/policy tests. Those Python tests also use synthetic execution results
for report and mutation regressions; they are not another real corpus execution.
No acceptance
rule, dependency, capacity, semantic primitive or constitutional guarantee is
introduced. Broader QS, PR, quantitative RS, exactness enforcement and release
gates retain their recorded incomplete status.
