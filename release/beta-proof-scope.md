# Beta production proof scope

This review applies the maintainer's [beta decision for #135](https://github.com/MGYamada/Qleisli/issues/135#issuecomment-7030099290)
to the registered production paths. The
[production boundary](../docs/src/reference/production-boundary.md#coverage-checks)
defines their classifications, checked subjects and retained evidence.
The [exact inventory](../tests/fixtures/verification_v029/coverage.json.xz)
retains the checkers, source bindings, regression selectors and proof gaps for
all 43 paths and 21 native modes.

The ledger admits two guarantees for the original decoded ordinary QLV1 root:
`QS-QLV1-OWNERSHIP-2026-01` and `QS-QLV1-SCOPE-2026-01`. Their recorded original
bytes, work bounds, root identity and request premises govern the current
production check. [The active ledger](../governance/guarantees.json) and
[current proof evidence](../governance/guarantees/current-evidence.json) carry
their exact scope. The release workflow reruns both registered verifiers
against the actual candidate.

QS-2026-01, PR-2026-01, RS-2026-01 and EXACT-2026-01 retain their broader pending
obligations. Every row below states the evidence the route can supply on the
current candidate. Component proofs, accepted handles, engineering measures,
runtime comparisons and target counts each carry their stated premises.
[Article VIII](../CONSTITUTION.md#article-viii--ratification-and-proof-maturity)
requires disclosure for the pre-v1 release and full discharge for a release
claiming full conformance.
