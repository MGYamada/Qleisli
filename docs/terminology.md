# Terminology and notation

English contracts authoritative, draft notation no API. Q<A> linear operation right incl empty owners, not state/effect/separability. Bit labels differ from CBit; pure=Unitary/Iso, frame includes pending/caller owners. Ordinary definitions user-checked, sealed meanings fixed. Verified IR means implemented acceptance, not checker/compiler proof. Coefficient domain includes exact operations/interpretation, no arbitrary angle license.

## Desugaring layer

Meaning-preserving convenience translation to specified core, exact order/phase/types/effects/owners/cleanup/budgets; adds no primitive or acceptance rule. Producers emit untrusted IR/evidence, never seals. Parsing/proof search/optimization separate; fresh output verification does not prove original-input correspondence. Unsupported angles cannot round to sugar; [approximation](coefficient-domains.md) independent contract. Rewrites rebind/recheck, numerical sharing removes no legacy rule. Unitarity/isometry no opaque inverse/control.

Use |x>,<x| in source-safe text or Unicode angle brackets in math, escape table bars. Distinguish adopted/implemented/tested/proved/reviewed and selection/tag/upload/publication; state models/premises/correspondence, actual results beside fixtures.
