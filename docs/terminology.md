# Terminology and notation

Editorial conventions do not change acceptance or turn tests into proofs. English
normative language/grammar/type/static/finite/machine contracts are authoritative;
Japanese discussion/legacy anchors support them. Draft notation is not a current API.
[Documentation map](documentation-map.md) identifies scope.

Basis labels differ from measured classical Unit/CBit/products and quantum owners.
Q<A> is a linear operation right, including zero width, not separability. A frame
includes caller/pending owners, possibly entangled. Pure means Unitary or Iso, not a
new effect. Ordinary definitions receive user checks; sealed operations have fixed
compiler meanings. Protected source/raw scopes have explicit different contracts;
general borrowing remains future. Verified IR means acceptance by the implemented
checker, not formal proof of the checker/compiler. Coefficient domain includes
arithmetic/equality/conjugation/interpretation, not an arbitrary trait or angle license.

## Desugaring layer

Meaning-preserving translation of convenience syntax/representations to already
specified core operations with explicit interfaces/ownership/effects. Adds no primitive
meaning or acceptance rule. This is a responsibility, not necessarily a crate/pass or
implemented universal importer. Resolved source/decoded adapters produce untrusted
IR/evidence/provenance; preserve evaluation order, empty owners, full phase, axes/
result order, effects, cleanup and specified limits. Hierarchy may retain calls/repeats
without flattening. Mathematical unitarity does not grant opaque inverse/control access.

Parsing/resolution/type checking, proof search, target selection and optimization are
separate; untrusted positioning never permits skipping source checks. Foreign parsing
alone is not desugaring; unsupported angles cannot become sugar by rounding.
[Approximation](coefficient-domains.md) requires its own request/error contract.
Independent verification checks produced properties; original-input correspondence
still needs translation proof/validation. Producers cannot issue checked handles or
release scratch. Rewrites rebind/invalidate/recheck evidence. A post-verification
numerical compatibility adapter removes no legacy acceptance rule.

Write kets |x⟩, bras ⟨x|, inner ⟨x|y⟩, outer |x⟩⟨y|, using U+27E8/U+27E9 and
ASCII vertical bar (escape inside Markdown tables). Source/URL/excerpts retain syntax.
Distinguish proposed/specified/implemented/finite-tested/paper-proved/machine-checked,
and version selection/tagging/upload/publication. Proof claims state models/premises/
remaining correspondence; fresh command results belong beside fixtures, historical
counts in immutable records.
