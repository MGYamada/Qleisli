## Additional authoring feedback

Effect errors now point to a cause of the strongest body effect and report both
derived and declared classifications. Provenance follows calls, branch joins
and coherent lifts without changing effect derivation; a declared observing
callee remains observing even when its body is empty. Imported calls point to
the caller. Unsupported grouped imports and direct static `h/x/z/t` arguments
include working rewrite examples. Snapshot failures name the copy/charge cause.
[Repair regressions](../../tests/repair_diagnostics.rs) check locations, both
branches, Unicode/CRLF, text/JSON and successful suggested rewrites.

Multiple-error recovery remains [A020-11](../v0.2.0-backlog.md#a020-11--independent-errors-require-repeated-checking-rounds):
it needs bounded independent checking and can be additive while retaining the
single-error public APIs. A020-12/13 record import/static-adapter boilerplate
and optional numerical presentation. These observations are not a measured LLM
benchmark, new source syntax, or changed default distribution.
