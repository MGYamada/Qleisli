## Target and status

**Target: Qleisli 0.3.0. Priority: important. Type: enhancement.**

The 0.3.0 Language Reference must distinguish **semantic unitarity** from **ancilla-free realizability on the same logical wires**.

A function accepted as `unitary` may denote a perfectly valid unitary operator while still being impossible to synthesize exactly over the declared target gate set without additional workspace. This is not a type-soundness bug; it is a boundary condition on the future **Physical Realizability** and **Resource Safety** theorems.

## New design constraint

The language must not equate

```text
unitary denotation
```

with

```text
exactly synthesizable over the selected gate set
on exactly the source program's logical wires
```.

The intended separation is:

```text
typing / verification
    ↓
exact mathematical denotation U
    ↓
physical-realizability / synthesis contract
    ↓
target circuit on logical wires + synthesis workspace
```

In particular:

> **`unitary` means that the denotation is unitary. It does not promise ancilla-free synthesis on the same wire set.**

This distinction belongs in the current formal realizations of the constitutional jurisdictions. v1 requires proof coverage, not a freeze of theorem statements.

## Motivating obstruction: determinant

For an embedded (k)-qubit gate (G) acting on (n) wires,

```text
det(G ⊗ I_(2^(n-k))) = det(G)^(2^(n-k)).
```

This gives a cheap invariant that can rule out same-wire exact synthesis.

### Three-wire QFT

For the standard three-qubit Fourier transform (F_8),

```text
det(F_8) = i
```

for the current Fourier convention.

For the ordinary exact Clifford+T generators embedded on three wires, the reachable determinant is restricted to `±1`.

Therefore the exact `std::transform::qft3` meaning cannot be synthesized by such a circuit on only its original three wires, even though its denotation is a valid unitary.

The obstruction is visible already in a controlled-T component: embedded on three wires,

```text
det(CT ⊗ I) = ω² = i
```

with `ω = exp(iπ/4)`.

### Four-wire reversible example

The following valid Qleisli program denotes the reversible map

```qli
unitary fn c3x(q: Q<((Bit,Bit),(Bit,Bit))>) -> Q<((Bit,Bit),(Bit,Bit))> {
    do ((a,b),(c,d)) <- q;
    pure ((a xor (b and (c and d)), b), (c, d))
}
```

On the computational basis it performs one transposition, hence

```text
det(c3x) = -1.
```

But on four wires the embedded Clifford+T / NCT generators in this profile have determinant `+1`, so any same-wire circuit generated from them has determinant `+1`.

Thus this `unitary` is again mathematically valid while failing ancilla-free exact realizability on the original wire set.

The reversible-logic version is the familiar parity obstruction: sufficiently small NCT gates embedded into four or more wires generate even permutations only.

## Theorem boundary

The constitutional Physical Realizability obligation is forward correspondence for an **accepted realization**, including its implementation workspace (#281).

For a clean-workspace unitary realization, a representative instance is:

```text
Accepted_now(P)
and CheckedRealization_now(P, target, C, W, evidence)
  imply

C (|ψ> ⊗ |0...0>_W)
  =
Meaning_now(P)|ψ> ⊗ |0...0>_W

for every |ψ>,
```

with the equality/phase convention, workspace contract, and arbitrary-reference behavior made explicit.

This is not a constitutional promise to synthesize every operator in a coefficient domain. A theorem establishing that such a circuit and workspace **exist for an entire domain** is optional target/profile completeness mathematics. If used, it may help produce evidence for the forward checker; it does not replace checking the actual accepted artifact.

For the Giles–Selinger exact Clifford+T domain, matrices over `Z[1/√2, i]` admit exact synthesis with at most one clean ancilla, even when ancilla-free synthesis is obstructed by determinant conditions.

Reference:

- Giles & Selinger, *Exact synthesis of multiqubit Clifford+T circuits*, 2013: https://arxiv.org/abs/1212.0506
- Shende et al., reversible-circuit parity obstruction: https://arxiv.org/abs/quant-ph/0207001

The Language Reference should state the general contract independently of any one synthesis theorem or gate set.

## Distinguish two kinds of workspace

This issue must not collapse backend synthesis workspace into #70's source-level ancilla syntax.

### Source-level workspace

`clean` / `dirty` in #70 are resources explicitly requested and manipulated by the Qleisli author.

They are part of source semantics and carry explicit restoration obligations.

### Backend synthesis workspace

A backend may require additional implementation qubits solely to realize an already verified exact operator over a selected gate set.

These qubits:

- need not appear as source-level owners;
- must not change the source denotation;
- must be initialized/restored according to the synthesis theorem used;
- must be represented in the backend correspondence/evidence;
- count toward target physical resource requirements.

For Giles–Selinger, the directly justified auxiliary resource is a **clean ancilla**. A future claim involving borrowed/dirty workspace requires a separate theorem; it must not be inferred automatically from the clean-ancilla result.

## Resource Safety consequence

Resource Safety must count both logical and synthesis resources.

A source-level width bound such as

```text
logical_width(p) <= 12
```

does not imply that the program fits on a 12-qubit target.

The relevant target-side condition is conceptually

```text
logical_live_width
+ explicit_source_workspace
+ backend_synthesis_workspace
+ routing / target-required workspace
<= target_capacity.
```

The exact accounting model can be refined later, but 0.3.0 must not state Resource Safety in a way that silently identifies logical width with physical implementation width.

This should connect directly to the later QCP design in #103.

## Cheap realizability invariants

The design should reserve a place for target-specific invariants that can detect mandatory workspace before full synthesis.

For exact Clifford+T-style profiles:

- determinant can rule out ancilla-free synthesis;
- for classical reversible permutations, permutation parity is the corresponding cheap invariant.

A checker/profiler may therefore report information such as:

```text
semantic_unitary: yes
same_wire_exact_realizable: no
reason: determinant/parity obstruction
backend_workspace_required: yes
workspace_contract: clean
```

This is a realizability/resource diagnostic, **not** a reason to reject the program as non-unitary.

Full synthesis need not be implemented in 0.3.0; the normative distinction and evidence/resource contract must be.

## Global phase must be explicit

Because determinant changes under global phase, the theorem statements must also fix the equality notion used at each layer.

The Language Reference must distinguish, where relevant:

```text
exact operator equality
vs
projective equality up to global phase.
```

Qleisli already treats phase as semantically relevant when it can become relative under coherent control. The Physical Realizability statement must therefore not silently quotient by global phase unless the exact boundary and compositional consequences are specified.

Coordinate this with #31.

## Required 0.3.0 specification

The Language Reference should define at least:

1. **Semantic unitarity** — what `unitary` promises.
2. **Target realizability** — what additional target/gate-set assumptions are required.
3. **Same-wire realizability** — explicitly a stronger, optional property.
4. **Synthesis workspace** — backend-private workspace distinct from source `clean`/`dirty`.
5. **Workspace restoration** — what state/equality obligation permits workspace removal from the target correspondence.
6. **Resource accounting** — logical width and physical implementation width are separate quantities.
7. **Phase equality** — exact vs projective equality at the realizability boundary.
8. **Evidence** — target artifacts record gate set/profile, workspace assumptions, and correspondence status.
9. **Diagnostics** — determinant/parity obstructions may report required workspace without invalidating `unitary` typing.

## Non-goals for 0.3.0

This issue does not require:

- a complete Clifford+T synthesis implementation;
- an optimal ancilla-count algorithm;
- a universal minimal-workspace theorem;
- target routing;
- hardware noise modeling;
- QCP implementation before 0.4.0;
- weakening the `unitary` effect;
- turning backend workspace into implicit source ownership;
- claiming that dirty/borrowed workspace is available when only a clean-ancilla synthesis theorem has been established.

## Design principle

> **Qleisli proves what the program means before asking how many physical wires are needed to realize it.**

Equivalently:

> **Semantic validity belongs to the language. Target realizability belongs to a correspondence theorem, and correspondence is allowed to require workspace.**

## 2026-10-07 scope clarification: known Clifford+T theorem vs cyclotomic generalization

For the Clifford+T coefficient domain `Z[1/sqrt(2), i]` (equivalently `Z[zeta_8,1/2]` in the present exact profile), the reverse-direction realizability statement is **not a research unknown**: Giles–Selinger gives exact synthesis with at most one clean ancilla, with the ancilla-free determinant conditions handled separately. The remaining Qleisli work is formalization, evidence transport, and binding the theorem to the actual emitted artifact/resource account.

Do **not** extrapolate that result automatically to the full cyclotomic tower or arbitrary `R_k`/colimit paradigms. The admissible ancilla count, dimension dependence, gate vocabulary, and relation between the level `k` and system size may change. Any such generalized completeness claim requires a separately checked theorem before it becomes part of a first-class paradigm contract.

Accordingly:

- Clifford+T / `R_3`-profile completeness may rely on the precise Giles–Selinger theorem after formalization;
- higher cyclotomic paradigms retain only the forward realizability obligations already established unless and until a matching converse theorem is verified;
- no dirty-workspace or arbitrary-`R_k` conclusion is inherited from the one-clean-ancilla Clifford+T result.
