## Scope and compatibility

[Shared source commands](../../src/bin/qleisli/source_commands.rs) centralize
checking, compilation, execution and fresh seeded sampling for text/JSON CLIs.
[Decimal parsing](../../src/bin/qleisli/options.rs), sized option validation and
sample serialization retain ranges, duplicates, exits, whitespace and work.
[Static flattening](../../src/frontend/compile/circuit.rs) encapsulates charged
owner/value/step emission. The simulator separates [state](../../src/sim/state.rs)
and [circuit execution](../../src/sim/circuit.rs). [QIRF](../../src/interchange/codec.rs)
shares explicit wire keys/bounded conversion; [hierarchy runtime](../../src/interchange/hierarchical/runtime.rs)
shares strict framing/process limits and final report construction after all
exact obligations pass.

Public Rust/IR/Lean contracts, source grammar, capacities, edition
and toolchains remain unchanged. Rust remains production-authoritative with
independent checking and disabled external schemas. Code sharing does not reduce
the trusted acceptance base or prove source preservation.

[Bug repairs for issues 146/147](../../tests/fixtures/issue_fixes_v025/README.md)
add a macOS-only rustix 1.1.3 safe syscall wrapper for held-parent no-follow
opening, without raising the deployment minimum, and check package-facing
documentation version pins. These compatible repairs are kept separate from
the broader refactoring in their PR and validation record.

[0.2.4 follow-up review](../../tests/fixtures/review_followup_v024/README.md)
adds compatible terminal export rewrites, opt-in declared qrate source selection,
metadata warnings, authoring diagnostics and manifest-derived corpus counts
([Issue 160](https://github.com/MGYamada/Qleisli/issues/160)). QFT2/QFT3 target
columns include exact phase, ordered axes and explicit clean synthesis workspace;
these are bounded validation results, not a backend correctness theorem or
Resource Safety certificate. Public phase/cost IR changes remain at 0.3.0 in
[Issue 165](https://github.com/MGYamada/Qleisli/issues/165).
