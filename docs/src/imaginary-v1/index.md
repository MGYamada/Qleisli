# Initial imaginary-v1 draft index

The `docs/src/imaginary-v1/` tree and
[lean-backend-plan-v0.3.md](../lean-backend-plan-v0.3.md) are the two documents/trees
retained by the v0.3.0-alpha cleanup and moved into the book's source tree.
Retired prose is available in Git history; new chapters follow adopted decisions,
actual code and proofs.

Six initial drafts completed the pre-0.2.0 design prerequisite. Their source is
imaginary/uncompiled, not adopted syntax/APIs, algorithm support or proofs. Completed
draft narratives are retired from docs; use immutable Git references below, preserving
original source/references under Apache-2.0. Active [requirements](requirements.md),
algorithm goal and V1-C1–C5
remain current. V1 requires executable Shor/QPE/Grover; walk/QSVT are stress tests.
